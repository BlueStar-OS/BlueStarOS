## 1. 先搞清楚：什么是"硬盘控制器"

你的 CPU 不能直接读写 eMMC 芯片上的 Flash 颗粒。中间隔了一个控制器。

```
┌─────────┐    MMIO 寄存器     ┌──────────────────┐    eMMC 总线     ┌──────────┐
│         │  ←──────────────→  │  eMMC 控制器      │  ←───────────→  │ eMMC 芯片 │
│  CPU    │   写命令寄存器      │  (SDHCI 兼容)     │   CMD/DAT 线    │ (Flash)   │
│         │   读状态寄存器      │  DWC MSHC IP      │   时钟线 CLK    │           │
│         │   读写数据寄存器    │                    │                 │           │
└─────────┘                    └──────────────────┘                  └──────────┘
```

类比你熟悉的 UART：
- UART 控制器：CPU 写 THR 寄存器 → 控制器按波特率一位一位发出去
- eMMC 控制器：CPU 写 CMD 寄存器 → 控制器按 SD/MMC 协议把命令发到 eMMC 芯片

本质上都是：**CPU 通过 MMIO 操作控制器寄存器，控制器负责和外设通信**。
